## 📖 الاستخدام

### بدء التشغيل

1. افتحي [bsky.app](https://bsky.app) وسجّلي الدخول
2. ستظهر لوحة البوت تلقائياً في الجانب
3. إذا لم تظهر، اضغطي **Shift + B**
4. فعّلي **🧪 وضع التجربة (Dry Run)** أولاً
5. راقبي السجل قبل تفعيل العمليات الحقيقية

### إعداد كلمة مرور التطبيق (للنشر)

1. اذهبي إلى **Bluesky → Settings → App Passwords**
2. أنشئي كلمة مرور جديدة
3. في البوت: تبويب **⏰ نشر** → الصقي كلمة المرور
4. ✅ سيتم تشفيرها تلقائياً

### نصائح للاستخدام الآمن

- ⚠️ ابدئي بـ **وضع التجربة** لمراقبة السلوك
- ⚠️ استخدمي **حد يومي** (مثلاً: 100 إعجاب، 50 متابعة)
- ⚠️ لا تتركي البوت يعمل 24/7 — استخدمي **الجدولة الزمنية**
- ⚠️ فعّلي **الاستراحة البشرية** لتجنّب الحظر
- ⚠️ راجعي السجل بانتظام
